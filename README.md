# Spending Tracker

## Project Goal
As a college student, I need to keep a budget, but it's hard to tell where my money goes. This Java command-line tool lets me enter purchases and see how much I spend in each category.

## MVP Scope
- Add a purchase (amount, category, date)
- Create new categories
- See the total for every category this month
- Show which category has the most spending
- Save purchases to a file and load them on startup
- Handle bad input

## Future Plans
- Budget limits per category with warnings
- Edit or delete a purchase
- Compare this month to last month
- Track subscriptions

## Tech Stack
- **Language:** Java
- **Libraries:** Built-in Java only
- **Storage:** CSV file (`purchases.csv`)
- **Tools:** Git, GitHub, terminal
